## 2. ⭐ いちばん危ないところ（V51 / V53）をどう担保したか

リードの申し送りどおり、**`#s-selected-filters` の CSS 閾値と `PANE_MIN_WIDTH` を同時に 1200 へ動かした**。

⭐ **構造上、この2つがずれない形になっている**（レビューが確認しやすいように書き残す）:

- `#s-selected-filters` の**既定は `display: none`**（メディアクエリの外・style.css の上のほう）で、
  **表示するルール `#s-selected-filters.has-selection { display: block }` は左ペイン一式と同じ
  `@media (min-width: 1200px)` ブロックの中にある**。
  ⭐ したがって **CSS 側は「メディアクエリの条件文1箇所」を直せば両方が動く**（別々の閾値を持っていない）。
- JS 側は `PANE_MIN_WIDTH`（`initAccordion` の `minWidth`）の1箇所だけ。

⚠️ **それでも「同時に動いたこと」は静的な読みでは証明にならない**ので、**1199px と 1200px の実測で確認した**（V51・V53・§3）。
