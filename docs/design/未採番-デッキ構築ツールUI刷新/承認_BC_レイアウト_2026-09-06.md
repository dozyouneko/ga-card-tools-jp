## 1. 承認の理由

- **M1〜M7 が全部 ✅**。⭐ **M1-b も適用して通っている**——`ReC-SHD` で絞ると4件すべて絵柄が追従し
  （**うち3件は `editions[0]` ではない**＝本当に追従している）、**レベル順・降順に変えても崩れ0**。
  バッジ・件数表示も一貫（⚠️ 共有URL(#20)はデッキ構築に存在しないので3つで正しい）。
- ⭐ **開発担当が V10 で実在の不具合を見つけ、レビューが独立に再現した**——
  `#view-editor { display: grid }` は UA の `[hidden] { display: none }` を**詳細度で上回る**ため、
  1280px以上で**他ビュー表示中も編集画面が居座る**（`#view-deck` が **+730px** 下へずれる）。
  ⚠️ ⭐ **`left`/`width` は一致するので「幅だけ見る検査」では素通りする型**だった。
  → **`#view-editor[hidden] { display: none }` の1行**で解消。**外す破壊試験で効いていることも実測済み**。
- ⭐ **破壊試験は報告＋レビューで計6本**。`--editor-bar-h` が固定値でないこと（通常名57px / 最長名102px・
  resize 追従・`top` と `max-height` が同期）まで実測されている。
