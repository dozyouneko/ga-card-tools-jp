## 6. 設計担当への確認事項

1. **iOS のズーム**: 641〜1199px では入力欄が **14px のまま**（`font-size: 16px` は 640px 以下に残したため、§14-3 の分割どおり）。**iPad などタブレット実機で入力欄にフォーカスしたときの拡大**は未確認です。**「16px も 1199px まで広げる」かどうかは寸法側の判断**なので、実装では動かしていません。
2. **トグルの文字サイズ**: 上記4-1 のとおり、`.filter-toggle` は 641〜1199px で **14px**・640px 以下で **16px** です（HeroUI 節の `.controls button` が勝つため）。**揃えるかどうか**はご判断ください（実装では触っていません）。
3. **`.filter-rest { margin-top: 10px }` の移設**（5-1）が意図と違えば戻します。
4. **G-3b（デッキ構築）は未着手**です。⚠️ **G-3a だけが入った状態では、641〜1199px でトップはスマホ表示・デッキ構築は上部パネルのまま**という食い違いが残ります（設計書 §14-5 の想定どおりですが、実物確認の順序としてご認識ください）。
