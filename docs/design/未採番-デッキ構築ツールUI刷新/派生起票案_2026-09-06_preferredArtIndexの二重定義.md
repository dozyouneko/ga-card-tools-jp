### ⚠️ ⭐ 症状はもう1つある（2026-09-06・D のレビューが発見）

**デッキ構築の「カード詳細モーダル」は、版の絞り込みにまったく追従しない。**
`GA_CARD_DETAIL.init()` に `preferredArtIndex` を渡していないため（トップは渡している）。

- ⚠️ **レアリティだけでなく、既存のエキスパンション絞り込みでも追従しない**（実測）
  ＝**左ペイン化のタスクが持ち込んだ劣化ではなく、前からある穴**
- ⭐ **タイル（`appendResults()`）は追従するのに、そこから開いたモーダルは追従しない**＝
  **同じ画面の中で絵柄が食い違う**
- ⭐ **共通化（本起票案の本体）と同時に直すのが自然**——`init()` に1つ渡すだけで済む

## 3. 直し方の案（⚠️ 設計書はまだ無い）

`shared/js/card-i18n.js` か `shared/js/card-search.js` に **1本だけ**置き、**参照する要素を引数で受ける**:

```js
// 例
GA_CARD_I18N.preferredArtIndex(imgs, { prefixes, rarities });
```

⚠️ **ページ側に残るのは「どの `<select>` / どの群から値を取るか」だけ**にする。
