### 3-5. `validate` に足す検査2本

⭐ **このリポジトリで生き残っているルールは、例外なく `validate` が見張っているもの。**

| # | 検査 | 落ち方 |
|---|---|---|
| **(i)** | `shared/css/**.css` が参照する `var(--…)` が、**すべて `shared/css/tokens.css` に定義されている** | 未定義が1つでもあれば **exit 1**（名前を全部列挙する） |
| **(ii)** | **`:root {` を持つCSSファイルの集合**が、許可リスト（`shared/css/tokens.css` / `cards/cards.css` / `tournaments/tournaments.css` / `tools/print/style.css`）と**一致する** | 増えても減っても **exit 1** |

- 成功時のログ（1行ずつ）:
  `shared css tokens in sync — N トークン参照 / 未定義 0`
  `:root owners in sync — 4ファイル`
- ⚠️ **(ii) は「減った」でも落とす**（許可リスト側の消し忘れを検出するため）。
- ⚠️ ⭐ **走査するのは配信されるCSSだけ**——`docs/` は**対象外**にする
  （設計モックの `モック_PC左ペイン_2026-09-02.css` と `モック_左ペイン化_2026-09-05.css` が
  `:root` を持っており、含めると**モックを増やすたびに `validate` が落ちる**）。
- ⚠️ ⭐ **`:root` は「コメントの中」にも現れる。** 実測（2026-09-06）: `shared/css/card-detail.css` と
  `shared/css/filter-chips.css` は、**どちらも本文に `:root` ルールを持たないのに、注意書きの文中に `:root` と書いてある**。
  ⭐ **素の文字列一致で数えると、この2枚が「持っている」側に混ざって (ii) が常に落ちる**。
  → **`:root` の直後に `{` が続く形だけを数える**か、**`/* … */` を除去してから走査する**。
  ⚠️ **同じ理由で (i) の `var(--…)` 収集もコメントを含めない**（説明文に書いた変数名を「参照」と数えない）。
- ⚠️ ⭐ **検査(ii)には限界がある**（2026-09-06・レビューが実測して発見）。**`:root` ではなく `body { --panel: red }` のようにページCSSでトークンを再定義すると、`validate` は緑のまま画面だけが変わる**（`html { … }` なら詳細度で `:root` が勝つので起きない）。⭐ **これは承知のうえで許容する**——任意セレクタでのトークン再定義まで見にいくと、**ページ固有のローカル変数を誤検出する**ため。⚠️ **緑を「トークンが1本化されている証明」と読まないこと**。
- ⚠️ **cron は `validate` を実行しない**。この2本が守るのは**人が編集するとき**だけ（#40 と同じ制約）。

## 4. B：レイアウト（案Z′・Q6）とブレークポイント（Q3）

### 4-1. 組み方

**`tools/deck-builder/style.css` に `@media (min-width: 1280px)` を1本足すだけ。⭐ JS の変更はゼロ。**

⚠️ **`body` にクラスを付け外ししない**（`route()` の付け忘れが**無言で他3ビューを壊す**）。
⚠️ **`:has()` で2カラム化を切り替えない**（無視されると壊れる用途には使わない＝既存方針）。

```css
@media (min-width: 1280px) {
  #view-editor { display: grid; grid-template-columns: 320px minmax(0, 1fr); align-items: start; }
  /* ⚠️ ⭐ 必須。`display: grid` は UA の `[hidden] { display: none }` を詳細度で上回るため、
     これが無いと 1280px以上で「他のビューを表示中も編集画面が居座る」（実測: #view-deck が +730px 下へずれる）。
     ⚠️ left/width は一致するので「幅だけ見る検査」では素通りする（2026-09-06・V10 で発見）。 */
  #view-editor[hidden] { display: none; }
  /* ⚠️ 既定を右列にしておく。要素が増えた日にその要素だけ左列へ落ちるのを防ぐ */
  #view-editor > * { grid-column: 2; }
  #view-editor .editor-bar { grid-column: 1 / -1; grid-row: 1; position: sticky; top: 0; z-index: 6; }
  #view-editor #search-top {
    grid-column: 1; grid-row: 2 / span 50; align-self: start;
    position: sticky; top: var(--editor-bar-h, 57px);
    max-height: calc(100vh - var(--editor-bar-h, 57px)); overflow-y: auto;
    padding: 14px 16px 24px; gap: 12px;
    border-bottom: none; border-right: 1px solid var(--border);
  }
  /* ペインの中は縦1列 */
  #search-top .row { flex-direction: column; align-items: stretch; }
  /* ⚠️ flex-basis 240px が「高さ240px」として効く。無いと閉じたペインが 579px → 987px になる */
  #s-name, #s-text { flex: 0 0 auto; width: 100%; min-width: 0; }
  #search-top .filter-row { grid-template-columns: minmax(0, 1fr); }
  /* リセット/検索の行だけ横並びに戻す。⚠️ :last-of-type では書かない（§4-3） */
  #search-top > .row-actions { flex-direction: row; }
  #search-top > .row-actions .btn { flex: 1 1 0; text-align: center; }
  /* ⚠️ サブタイプ157種はペインに収まらない。⚠️ shared/css/filter-chips.css には書かない（R1） */
  #search-top .fgroup .chips { max-height: 200px; overflow-y: auto; }
  /* 「すべて表示」中は上限を外す（無視されても1つ前の見た目に戻るだけ＝fail-open なので :has() 可） */
  #search-top .fgroup:has(.chips-rest:not([hidden])) .chips { max-height: none; overflow-y: visible; }
  /* ⚠️ チップ領域がスクロールコンテナになると Tab のフォーカスが枠外に出る */
  #search-top .fgroup .chip { position: relative; }
}
```

### 4-2. `--editor-bar-h`（`.editor-bar` の実測高さ）

⚠️ **固定値で書かない**（スマホ絞り込み導線の `--printbar-h` と同じ流儀）。
`.editor-bar` は**デッキ名の長さ・フォーマットバッジ・画面幅**で 52〜102px の間で変わり、
**sticky の `top` とペインの `max-height` の両方が同じ値に依存する**。

- 設定するのは `#view-editor` を表示した後（`openEditor()` の `renderEditorBar()` の直後）と、
  **`resize`／デッキ名変更／フォーマット変更のあと**
- 値は `Math.round(bar.getBoundingClientRect().height)` を `document.documentElement.style.setProperty()` で
- ⚠️ **CSP `style-src 'self'` があるので `<style>` 注入は使えない**（CSSOM／`style` プロパティ経由は可）

### 4-3. ⚠️ `.row-actions` クラスを1つ足す

`tools/deck-builder/index.html` の**リセット/検索の行**に `row-actions` を足す:

```html
<div class="row row-actions">
  <button id="s-reset" class="btn" type="button">リセット</button>
  <button class="btn btn-primary" id="s-search">🔍 検索</button>
</div>
```

⚠️ ⭐ **`#search-top > .row:last-of-type` で書かないこと。** 将来 `#search-top` の末尾に div を1つ足した瞬間に
**当たらなくなり、リセット/検索が縦積みに戻る**（モック作成中に実際に踏んだ）。

### 4-5. ⭐ B の周で一緒に片づけるもの（A の承認で決まった・1.1）

```js
function preferredArtIndex(imgs) {
  const pre = GA_CARD_SEARCH.setPrefixes(el.sSet.value);
  const rar = el.sGRarity ? el.sGRarity.getValues().map(String) : [];
  if (!pre.length && !rar.length) return 0;

}
```
