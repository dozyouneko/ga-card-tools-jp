```markdown
# デッキ構築ツールUI刷新
- カードDBと同じように検索条件は左ペインに
- 検索結果はタブを生成する。過去の検索結果も残るように
- デッキタブ、統計タブは削除できないが検索結果タブは削除できるようにする。
- 検索結果タブの上部に何の条件で検索されたかを表示する。
- 今まで通り検索結果からデッキへカードを投入できる
- 検索条件はカードDBと統一する
- UIはカードDBと同じようにHeroUIを利用する
- omnidex提出用コピーやなども左ペインに納められるなら納める
# サイドボードプランメモ
- 対戦相手を想定して、サイドボードのプランを事前に登録しておき、これを見ながらゲーム中サイドボードを変更したりできる機能
- 項目としては以下の項目がある
	- 想定される対戦相手
	- メインデッキから抜くカード
	- サイドデッキから入れるカード
	- メモとして活用できるテキスト入力欄
- タブでサイドボードプランメモを複数管理
	- 統計が並んでいるところにタブを追加したり削除したりできるようにする。
# フォーマット検索整備
- よりユーザーが欲しい情報を見れるように整理する
- リストを以下のように改修
	- スタンダード使用可
	- スタンダード禁止
		- シーズンバンと通常の禁止のサマリー
		- パンテオン限定やドラフト限定を含めない
	- パンテオン使用可
	- パンテオン限定
	- パンテオン禁止
		- スタンダード限定やドラフト限定を含めない
	- ドラフト使用可
	- ドラフト限定
	- ドラフト禁止
		- スタンダード限定やパンテオン限定を含めない
# デッキ構築ツールでのトークン表示
- デッキに投入されたカード内で使用されるトークンを表示する機能
```
