## 1. 承認の理由

- **M1〜M7 が全部 ✅**、⭐ **M1-b も適用して通過**。**§14-6 の G-3b 必須条件4点も充足**。
- ⭐ **23幅スイープで「境界が 1199↔1200 のちょうど1px」であることを示した**
  （境界の直前直後 639/640/641・859/860/861・1198〜1201 を含む）。
  ⚠️ ⭐ **G の目的は「見え方を2つだけにする」＝中間の形がどの幅にも出ないこと**なので、
  **点で測るのではなく帯で潰す**のが正しい当て方。⭐ **V43 が求めていたものに、これで初めて全部答えた。**
  ⭐ **resize 依存でないことを各幅の新規ロードでも検算している**のも的確
  （⚠️ **resize だけで測ると、初回ロードでしか出ない不整合を見落とす**）。
- ⭐ **破壊試験2本**——**「帯ごと広げる」を CSSOM で再現し、§14-3 の警告（1199×900・角丸0・
  `.artgrid` 2列・16px）が実在することを証明**したうえで、**出荷版は 1199px でも 860×106.88・角丸16px**
  であることを対照した。⚠️ ⭐ **設計書が「やってはいけない」と書いたことの実在を、
  実装後のコードで確かめている**——これが無いと「分割した」ことの意味が測れない。
- ⭐ **全数回帰（39セレクタ×34プロパティ×19幅）で、差分が 861〜1199px にしか無いことを示した。**
  ⚠️ **620 / 640 / 860 と 1200以上がすべて 0** ＝ **「移すのは4つだけ」が構造的に守られた証拠**。
- ⭐ **JS が1バイトも変わっていない**（§14-6 の必須条件3「CSS だけで完結するはず」がそのとおりだった）。
- **dev の確認事項②（他3ビューの回帰）はレビューが実施済み**
  （3ビューを**実際に開いた状態**で 6幅×3ビュー＝18通り・差分0）＝ **やり直し不要**。

## 2. 設計判断

### S-1 ⭐ **F-a に含める**（独立の単位は立てない）

⚠️ 新設ブロック内のコメントが「**上**の寸法系の16px」と書いているが、
**寸法系（`@media (max-width: 860px)`）は同じコミットで下へ移動している**
（同ブロックの見出しは「下」と正しい＝**内部で食い違っている**）。

⭐ **裁定: F-a に含める。ただし設計書に明記して逸脱にしない**（→ 1.10 の §12-3）。

#### ⚠️ vendor除外コメントの件と扱いを変える理由

| | vendor除外コメント（独立の単位にした） | 今回 |
|---|---|---|
| 何が書いてあったか | ⭐ **「外すと赤くなる」という、検査の挙動そのものを誤って説明する断定** | **方角の言い間違い**（「上」／「下」） |
| 読んだ人が取りうる誤った行動 | ⚠️ ⭐ **断定を信じて検査を消す・緩める** | ⭐ **無い**（「上」を探しても寸法系は見つからないだけ） |
| 実害 | **規約が消える** | **読みにくいだけ** |

⭐ **同じ扱いにする理由が無い。** ⚠️ **ただし「放置すると腐る型」であることは同意**なので、
**次に同じファイルを触る単位（F-a）で必ず直す**——⭐ **「ついで」ではなく設計書の指示にする**
（⚠️ **書かないと dev が触れないか、触って逸脱扱いになる**）。

⭐ **中身そのものは正しい**（デッキ構築のトグルの 16px は**このルールだけ**が出所で、
`860px` 側の `.search-top input, select, .btn { font-size: 16px }` は `.filter-toggle` に当たらない）。
**直すのは方角の1語だけ。**

### S-2 ⭐ **追加の対応は不要**（理解のとおり）

閾値の非重複を守るのが今もコメントだけなのはそのとおりだが、
⭐ **受け皿は `E-add-1` の検査②に切り出し済み**（設計 §11-9・V55）。

⚠️ **念のため検算した**——検査②は「`min-width` の集合が `PANE_MIN_WIDTH` ただ1つ／
`max-width` はすべてそれ未満」なので、**G-3b 後のデッキ構築（`min-width` は 1200 の1本／
`max-width` は 1199 / 860 / 640 / 620）は通り、`1199 → 1200` に間違えた瞬間に落ちる**。
⭐ **非重複はこれで担保される。**

### dev の確認事項① ⭐ **§12-9 の項目10 を「トップ限定」に直す**

⭐ **デッキ構築側のトグルの `font-size` は全幅・before/after とも 16px で不変**
（レビューが実測）。⚠️ **「640px 境界で font-size が変わる」はトップだけの話**で確定したので、
**§12-9 の項目10 をトップ限定の記述に直す**（→ 1.10）。
