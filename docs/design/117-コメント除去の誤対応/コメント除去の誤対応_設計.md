## 1. 何が起きているか（1行）

`scripts/validate.mjs` のコメント除去

```js
const stripJs = (s) => s.replace(/\/\*[\s\S]*?\*\//g, " ").replace(/(^|[^:])\/\/[^\n]*/g, "$1");
```

は **ブロックコメントを先に落とす**ため、**行コメントの中に書かれた `/*` を「ブロックコメントの開始」と誤認**し、
ずっと後方の `*/` と対にして**間のコードを丸ごと消す**。両ページの冒頭にある
`// 訳データ(#22 フェーズ2)。… data/tl/*.js …` の `/*` がこれを引き起こしている。
