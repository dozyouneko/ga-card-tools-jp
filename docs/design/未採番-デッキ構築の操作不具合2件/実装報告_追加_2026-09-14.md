## 4. 差分が設計書の想定と食い違った点

- **V12 の測定前の `.pane-scroll` の位置が 12 → 324 に変わった**（`initialScrollTop`。V12 の判定は 0 に戻してから測るので影響なし）。

  **マウスの座標で押す（`page.mouse.click`）と変更前・変更後とも `scrollTop` は 0 のまま**。⭐ **テストハーネス側の現象で、ユーザー操作での挙動は変わっていない**と判断した

  | 押し方 | 変更前（`8e5f413a`） | 変更後（`0d3da4e9`） |
  |---|---|---|
  | `page.click()` | 0 → 12 | 0 → 324 |
  | `page.mouse.click(x, y)` | 0 → **0** | 0 → **0** |
