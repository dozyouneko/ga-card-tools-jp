### 3. 判断済み事項（実装側で決め直さないこと）

| # | 決めたこと |
|---|---|
| **一本化** | ⭐ **規則（どの裁定を・どういう順で・エラッタか）を `card-i18n.js` の `rulesOf()` 1箇所に集約する。HTMLの字面は各ページに残す**（`flavorOf()` の前例と同じ形）。⚠️ **#109（ハイライト規則の二重定義）と同じ型を最初から作らない** |
| **エラッタの見せ方** | **金の `エラッタ` バッジ＋左罫線**／単なる裁定は**灰の `裁定` バッジ**。エラッタを持つときだけ警告行 `⚠️ エラッタがあります（上の効果文は印刷時のテキストのままです）`。⚠️ **「裁定が優先される」とは書かない**（公式が明言していない） |
| **置き場所** | ⭐ **モーダルも静的ページも「効果文の直後」**。⚠️ **静的ページの裁定ブロックを収録セット表の後ろから移す**のが今回の範囲 |
| **並び順** | ⭐ **①エラッタが先 → ②日付の降順 → ③本文の昇順 → ④タイトルの昇順**の**全順序**（実データで同値0を確認済み）。⚠️ **`localeCompare` ではなく素の比較**（ロケール非依存） |
| **対象版** | 複合タイトルの余り（`DTR` 等・全部セットprefix）は **`対象版: DTRSD・P25` として prefix のまま出す**。⚠️ **日本語セット名に変換しない**（#40 と同じ「更新の号令が無い辞書」を増やさないため） |
| **本文の扱い** | **`escapeHtml()` だけ**（`renderEffect()` は通さない）。**trim する**（末尾改行が3件） |
| **折りたたみ** | **しない**（常に開いた状態） |
| **使ってよいトークン** | ⚠️ ⭐ **`--accent` / `--muted` / `--panel-2` / `--text` だけ**（`tokens.css` と `tournaments.css` の**両方**にあるもの）。⚠️ **`--border` / `--danger` は `tournaments.css` に無い**ので、フォールバック無しで書くと**大会ページだけ静かに壊れる**（`validate` は緑のまま通る）。⚠️ **色は `color-mix(...)` で書く**（直値は検査が exit 1） |
