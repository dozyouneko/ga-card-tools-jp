### 4. ⚠️ 実装で踏みやすい落とし穴（1.1 で足した分）

1. ⚠️ ⭐ **モーダルの `<details>` は `MODAL_HTML` に固定で存在するので、前のカードで開いたら `open` が残る。**
   **`render()` のたびに `removeAttribute("open")` すること**（**V29** で測ります）
2. ⚠️ ⭐ **`.rules-block ul { display: grid }` は UA の `[hidden] { display: none }` に詳細度で勝つ。**
   **`.gacd-modal .rules-block ul[hidden] { display: none; }` と `.rules-fold[hidden] { display: none; }` を明示**すること
   （既存の `.add-print[hidden] { display: none }` と同じ手当て）
3. ⚠️ **中身が0件の `<details>` を出さない**（エラッタのみ 115枚）。**押しても何も出ない `<details>` は壊れて見える**（判断8・**V27** が 478 になったら不合格）
4. ⭐ **`summary` の色に使う `--accent-2` は `tokens.css` にも `tournaments.css` にもある**ので、**フォールバック無しで書いてよい**
