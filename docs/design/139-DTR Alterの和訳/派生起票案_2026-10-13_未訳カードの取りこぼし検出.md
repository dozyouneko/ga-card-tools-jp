**呼び名「未訳カードの取りこぼし検出」**（派生起票案・#139 から・2026-10-13 実測）

## 症状

⚠️ ⭐ **`jinzhuo-bands-of-virtue`（Jinzhuo, Bands of Virtue・PRXY #013）が約7週間、未訳のまま誰にも気づかれなかった。**

- カードページの初出は **`03ff53a5`（2026-08-27 の定期再生成）**
- `data/tl/prxy.js` は **`3333926a`「Translate Proxia's Vault (PRXY) — 11 cards; set complete」で完了扱い**
- その後 PRXY は **13枚**に増え、1枚は訳されたが本件は残った

⭐ **型は「既存セットにカードが1枚増えた」。** どの検出経路にも引っかからない（実測）:

| 既存の経路 | 反応するか | なぜ |
|---|---|---|
| `meta.sets` の検査（#40） | ❌ | **新しい prefix にしか反応しない**。PRXY は登録済み |
| `meta.subtypes` / `meta.rarities` の検査 | ❌ | **未訳カードは `data/card-meta-index.json` に載らない**（`gen-card-meta-index.mjs` は翻訳済みslugだけを回す）ので、そもそも見えない |
| `build:cards` の完走サマリ `カード2535ページ(和訳あり2494)` | ⚠️ | **差は出ているが内訳が無い**。⭐ **新セット直後は41枚未訳が正常**なので、人には異常と読めない |
| `check-terminology.mjs` | ❌ | 用語の話であって未訳の話ではない |
| `npm run validate` | ❌ | 未訳の存在を一切見ていない |

⚠️ ⭐ **実害**: 未訳カードは **JPモードの検索索引に載らない**ので、**日本語で検索しても永久に出てこない**。
発売済みのカードでこれが起きると、**サイトの存在意義（翻訳を届ける）がそのカードについてだけ満たされない**。

## ⭐ 成立する判別子（実測で確かめた）

> **未訳カードのうち、その版の prefix に対応する `data/tl/<prefix を slug 化したもの>.js` が既に在るもの**

| 測ったこと（2026-10-13・スナップショット 2,535枚） | 値 |
|---|---|
| 未訳カード | **41枚** |
| ⭐ **判別子に当たるもの** | **1件**（`jinzhuo-bands-of-virtue` / PRXY） |
| 当たらないもの | **40件**（DTR Alter。⭐ `data/tl/dtr-alter.js` がまだ無い） |
| **誤検出** | **0件** |

## ⚠️ ⭐ `exit 1` にはできない（理由は「未訳は常にありうる」より強い）

⚠️ ⭐ **この判別子は #139 のバッチ運用そのもので壊れる**:

> **#139 のバッチ1で `data/tl/dtr-alter.js` を新設した瞬間、残り26枚が全部
> 「訳ファイルが在るのに未訳」になって exit 1 になる。**

⭐ **「バッチごとに公開する」はユーザーが明示的に選んだ運用**（2026-10-13:「翻訳されているものをいち早く届ける」）なので、
**それを止める検査は入れられない**。⚠️ **「未訳は常に存在しうるから」という一般論より、こちらが決定的な理由。**

## 希望する対処（案）

⭐ **`npm run validate` の成功行として「報告」する**（exit code は変えない）。
⚠️ **スナップショットが無ければ「スキップ」と明記して緑にする**（`meta.rarities` の検査と同じ流儀）。

```
untranslated cards — 41枚（新セット 40 / 既訳セットの取りこぼし 1: jinzhuo-bands-of-virtue）
untranslated cards check skipped — スナップショットがありません
```

- ⭐ **`check-terminology.mjs` と同じ「一覧に出すだけ」の流儀**（⚠️ 赤くすると使われなくなる検査に育つ）
- ⭐ **取りこぼしが 0件のときも行を出す**（0になったことが見えるように）

### ⚠️ 残る穴（承知のうえで書くこと）

⭐ **訳ファイルが無い prefix にだけカードが増えた場合は沈黙する。**
**実測: 訳ファイルを持たない prefix が 24種ある**
（`SP4` / `PP1` / `EVP` / `DOA 1st` / `RDO 1st` / `SP2` / `SLC` / `MRC 1st` / `DOASD` / `PRDEVP` / `SP1` /
`PTMLGS` / `RDOA` / `KSP` / `ALC 1st` / `ReC-SHD` / `FTCA` / `ReC-SLM` / `DEMO23` / `P22` / `RDOEVP` / `PRDG` / `GSC` / `DTR Alter`）。
これらは**別セットと slug を共有しているので全カードが訳済み**だが、**そこへ新カードが1枚足されても判別子は当たらない**。

⚠️ ⭐ **この穴は「別の設計」が要る**（時計で判定する＝CLAUDE.md が禁じている／
カードページの初出コミット日時を見る＝`validate` をオフライン前提から外す）。
⭐ **穴があることを成功行か設計書に明記して、塞がないことを選ぶ**のが本件の推奨。
