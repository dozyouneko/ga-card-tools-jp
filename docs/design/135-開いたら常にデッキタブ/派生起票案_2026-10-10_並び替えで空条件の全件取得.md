# デッキを開いた直後に「並び替え」を触ると、条件が空の検索タブができて全件取得（50ページ）が走る

## 症状（⭐ 設計担当が 2026-10-10 に実測して再現させた）

デッキ構築ツールで **検索タブが1つも選択されていない状態**（＝#135 の後は**デッキを開いた直後が常にこれ**）で、
左ペインの **「並び替え」（`#s-sort`）を数値項目（レベル・パワー・ライフ・メモリーコスト）に変える**と:

| 何が起きるか | 実測値 |
|---|---|
| ⚠️ **新しい検索タブができる** | 保存タブ2つのデッキ → **「検索3」**が追加されて選択される／保存タブ0のデッキ → **「検索1」** |
| ⚠️ **条件が空のまま検索が走る** | 条件の箱が **`絞り込みなし（全カード）` / `並び レベル順 ▲ 昇順`** |
| ⚠️ ⭐ **全カードの取得が始まる** | `api.gatcg.com/cards/search?&sort=collector_number&order=ASC&page=1&page_size=50` から **page=50 まで**。件数欄は **「読み込み中 N/50 ページ…」** |
| ⚠️ **数十秒ふさがる** | 6秒時点で **13件**・26秒時点で **43件**・完了までに **50件**（⚠️ **絶対値は観測窓で動くので、判定には使わない**） |

⭐ **「昇降順」ボタン（`#s-order`）だけを押した場合は軽い**: 既定の名前順のままなので
`sort=name&order=DESC&page=1&page_size=24` の **1リクエスト**で終わる（⭐ **それでも「条件が空の新しいタブ」はできる**）。
⚠️ ⭐ **重くなるのは数値ソートのときだけ**（#44 の「全件取ってローカルで並べる」経路に落ちるため）。

## 原因（コードの1点）

`tools/deck-builder/app.js` の `updateActiveSearchTab()`:

```js
function updateActiveSearchTab() {
  const tab = activeSearchTab;
  if (!tab) { runNewSearchTab(); return; }   // ← ここ
  …
```

⭐ **「並び替え・昇降順は表示中のタブをその場で更新する（タブを増やさない）」**のが #85 §2-3 の仕様で、
**持ち主がいないときのフォールバックが `runNewSearchTab()`**（＝フォームの現在値で新しいタブを作って検索する）。
**フォームは空なので、条件なしの全カード検索になる。**

## ⚠️ これは既存挙動である（#135 の回帰ではない）

- ⭐ **#85 の V9 で「検索タブが1つも無い状態では新しいタブができる（＝それまでの空条件の検索が走るを踏襲）」として明示的に許容した**
- ⭐ **実測でも、保存タブが無いデッキでは #135 の前後で同じ**（`活性タブが null` という同じ分岐に落ちる）
- ⚠️ ⭐ **#135（開いたら常にデッキタブ）で変わったのは「この状態になる場面が増えた」こと**——
  **以前は保存タブのあるデッキを開くと最後のタブが自動で選ばれていた**ので、並び替えは「その場更新」に入っていた

## 案（⚠️ どれを採るかは設計で決める。実装側で決めない）

| 案 | 内容 | 懸念 |
|---|---|---|
| **A** | **検索タブが1つ以上あるなら、最後に作ったタブ（または直前に見ていたタブ）を更新する** | ⭐ 期待に近い。⚠️ **「直前に見ていたタブ」を覚えるのは #135 で捨てた `active` の復活**になりうる——**保存はせず、セッション内の変数だけで持つ形なら両立する** |
| **B** | **タブが無い（または選ばれていない）ときは、フォームの値だけ変えて検索しない** | ⚠️ ⭐ **「並び替えを変えても何も起きない」＝無言の劣化**。左ペイン化_設計 §5-2 が**戻すなと明記したガード**そのものなので、**採るなら注意書きごと差し戻す判断が要る** |
| **C** | **新しいタブを作るのは今のまま。ただし条件が空なら数値ソートの全件取得をしない**（名前順の1ページだけ出す／あるいは「検索語か絞り込みを選んでください」と出す） | ⭐ **重さだけを取り除く最小の案**。⚠️ #44 の「数値順は全件取ってローカルで並べる」規則に**条件つきの例外**を作ることになる |
| **D** | **何もしない（許容のまま）** | ⚠️ ⭐ **デッキを開いて並び替えを触るだけで数十秒ふさがる**のは、#135 で場面が増えたぶん目に付きやすい |
