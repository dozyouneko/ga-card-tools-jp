## 開発担当・レビュー担当からの確認事項への回答（3点）

### 1. push のタイミング → **`push待ち`。⚠️ 復旧後の初回cronより前に送る**

- 本コミットは**本番配信物**（`data/**`・`cards/**`・`scripts/**`・`TRANSLATION.md`）を含むので `push待ち`
- ⚠️ **送るときは `git pull --rebase origin main` を先に**（既に未pushが**33コミット**溜まっている）
- ⭐ **追加の申し送り（設計担当）**: **cron（03:00 JST）が復旧後に先に走ると、`cards/**` を
  旧コードで再生成してコミットするため、後から rebase すると同じファイルで衝突する。**
  **復旧した日のうちに push の可否を判断する**のが最も安全

### 2. APIドリフト80ファイル＋新カード1枚の扱い → ⭐ **手で取り込まない（放置してcron復旧に任せる）**

**開発担当が除外した判断・レビューの「除外して正しい」判定を、設計担当としても支持する。**

- 陳腐化の内訳（裁定セクション・新規カード・セットページ・`sitemap.xml`）は**すべてcronの `git add` 対象8パスの内側**にあり、
  **復旧後の初回cronが自動で追従する**（`npm run validate` の `cron git add paths in sync — 8パス` で列挙の一致は機械検査済み）
- 放置しても**表示は壊れない**（裁定が出ないだけ＝fail-open）
- ⚠️ **手で取り込むと、本タスクのコミットに無関係な本番配信物が混ざる**（#71 で差し戻しになった型）。
  ⭐ **cronが止まっているという理由だけで原則を曲げない**
  （⚠️ フレーバー側の14ファイルを「残す」と決めたのは、**剥がすと修正ごと消えるという別の事情**による例外であって、
  「cronが止まっているから何を混ぜてもよい」という意味ではない）

⚠️ **PRD発売（2026-08-21）を停止中に跨いだ**ため、復旧後の初回cronの自動コミットは通常より大きくなる。
⭐ ユーザー承認済みの運用どおりだが、**`meta.sets`（#40）の追記だけは自動化されていない**ので、
**復旧後にPRD系の新prefixが `meta.sets` に足りているかを人が確認する**こと。

### 3. `check-terminology.mjs` の既存の表記ゆれ報告11件 → ⭐ **起票する。ただし内訳は「10件＋誤検出1件」**

⚠️ **「コーパス全体の表記統一は #12 の範疇」と即断しかけたが、実データを見たら違った。**
設計担当が `tmp/api-cache/cards-snapshot.json` と `data/tl-effects.json` を突き合わせて切り分けた:

| 報告 | 実体 | 判断 |
|---|---|---|
| **`starcall` × 10** | ⚠️ **表記ゆれではない。** 10枚の英語原文にあるのは動詞 `starcall` ではなく**キーワード能力 `Starcalling`**（JP訳は「**スターコーリング**」）。`matchedTerms()` は `\b`+前方一致なので**キー `starcall` が `Starcalling` に当たってしまい**、日本語側で `jp` の中核「**スターコール**」を探して**見つからず、ハイライトも用語解説も出ない** | ⭐ **起票する。本タスクとまったく同じ型の不具合**（辞書と既訳の字面が合わずハイライトが黙って落ちる） |
| **`charge` × 1** | ⭐ **誤検出。** `charge-the-soul` の英語原文に出る `charge` は**そのカード自身の名前**（`load Charge the Soul into…`）で、JP訳は日本語のカード名になる | **対応しない**（不具合ではない） |

⭐ **`starcall` / `スターコール` 自体は正しい登録である**（`starcalled`→「スターコールされた」等、
**動詞として6箇所で実際に使われている**）。抜けているのは**キーワード `Starcalling`／スターコーリング**のほう。

⚠️ **設計時の注意（起票案に明記した）**: `terms` に `starcalling` を足すだけでは直らない可能性がある。
**前方一致のため `Starcalling` は `starcall` にも当たり続ける**ので、
**`matchedTerms()` が最長一致を採るのか両方返すのかを確認してから**直し方を決めること。
→ **起票内容は `docs/design/未採番-スターコーリングのハイライト欠落/起票案_2026-08-26.md` に用意した。**
