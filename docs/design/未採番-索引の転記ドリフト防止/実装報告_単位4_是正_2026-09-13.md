
  §8-4-c は **「`firstAdditions()` 自体は変えない」と明示している**ので、**実装側では決めずに §6 で確認を仰ぐ**。
- ⭐ **S-2 のねらい（「Node のスタックトレースがそのまま出る」を読める形にする）は満たしている**:

### ⚠️ Q1. V56 の `fatal: not a git repository …`（git 自身の1行）を消すか

- **現状**: 標準エラーは **git の1行 ＋ 自前の1行 = 2行**（§4）。設計書 V56 の期待値は**1行だけ**。

  自前のメッセージ（`Command failed: git …`）は**コマンド行しか言わない**。
