1. #58 メインデッキのカウンタ

カウンタの表記を N / 60 → N / 60以上 に変え、 61枚以上を .over（赤）にしない。60枚以上は .ok（緑）で、メーターは100%で止める。 マテリアル（12枚）とサイド（15pt）は従来どおり超過を赤にする（どちらも「最大」だから正しい）。

2. #59 マテリアルゾーンのLv0チャンピオン注記

マテリアルゾーンのメーター直下に注記を1行足す。マテリアルに1枚以上あって、Lv0チャンピオンが0枚のときだけ出す （空のマテリアルには出さない ＝ 新規デッキを開いた瞬間に警告しない）。 Lv0チャンピオンが入っていれば注記は消える（「入っています」とは言わない）。 タブ帯の警告バナー（#deck-warn）には出さない — 構築途中は必ず未達で、常時点灯するため。

6. 変えないもの

・タブ帯の警告バナー（#deck-warn）— 表示条件も理由ラベルも一切変えない。🚧 は入れない
・マテリアル / サイドのカウンタ・色分け — どちらも「最大」なので現行の ok(=上限) / over(>上限) が正しい
・統計のゾーン別カード・合計の内訳（マテリアルデッキ 12枚 等）
・共有閲覧画面のゾーン見出し（メインデッキ 62枚）— メーターもカウンタも無いので影響なし
・omnidex提出用コピー / デッキ画像出力
・API・DB・生成物 — 変更なし（cards/ sets/ の再生成は不要）
