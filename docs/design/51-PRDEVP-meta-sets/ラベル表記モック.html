結論から — 幅は争点になりません

追記するラベルが長すぎてレイアウトを壊すのでは、という懸念が最初にありました。 既存56ラベルを機械的に測ったところ、そうはならないことが確定しています。

<select> の幅も一覧カードの折り返しも最長ラベルで決まっています。 候補Aは既存最長より9文字短いため、どの画面もレイアウトは1pxも変わりません。
→ 判断すべきは幅ではなく、先頭ドット＋全小文字という意匠が日本語サイト上で読めるかだけです。

以下、実際に文字列が出る3つの面を、現状と変更後で並べます。 枠の中は本番CSSをそのまま転記しており、色・字送り・余白は実物と同じです。

候補

日本語ラベル案は検討から外しました（理由は下表の脚注）。

案ラベル文字数既存56件との整合
A 推奨 .asphodel/paradise Event Pack（PRDEVP） 37 完全に一致。公式セット名をそのまま採用
C Asphodel/Paradise Event Pack（PRDEVP） 36 読みやすいが公式表記と異なる（先頭ドットを削り大文字化）
日本語ラベルを候補にしなかった理由。 既存56ラベルを検査したところ日本語を含むものは0件で、 「英語セット名＋（PREFIX）」が例外なしの規則になっています。 ここだけ日本語にすると <select> の並びで浮きます。
