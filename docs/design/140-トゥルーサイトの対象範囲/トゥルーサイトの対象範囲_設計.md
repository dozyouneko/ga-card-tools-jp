## 1. 症状（⭐ 設計担当が独立に実測して再現）

`cards/extraction-incision/` の同じページに、**意味の違う英文と和訳が並んでいる**。

| 節 | 文面 |
|---|---|
| 効果（日本語） | 「**トゥルーサイト** *（この攻撃は**ステルス**を持つ**ユニット**を対象にできる。）*」 |
| 効果（英語原文） | `**True Sight** *(This attack can target objects with **stealth**.)*` |

- ⭐ **ライブAPIで1回確かめた**（`GET https://api.gatcg.com/cards/extraction-incision`・2026-10-15）。
  `**` を除去して比較した結果は `this attack can target objects with stealth` ＝ **現行の公式英文は `objects`**
- `unit` ⊊ `object` なので、**和訳が公式より狭い範囲しか言っていない**
- ⚠️ 公式API側が `units` → `objects` に書き換えた。**`3039489b`（2026-10-04）時点では `units`**（実測）

⚠️ ⭐ **起票案の英文の引用は太字位置が1箇所ずれている**（起票案は `target **objects** with stealth` と書いたが、
実際は **`stealth` が太字で `objects` は素**）。⭐ **結論は変わらない**が、
**`**` を除去せずに grep すると一致しない**ので、照合する人は必ず除去してから比較する（CLAUDE.md の #73 の節）。

### 1-1. ⭐ 前例があるので新しい訳語は決めなくてよい

`objects` 側の英文を持つカードは **3枚**（実測）。うち2枚は**すでに「オブジェクト」と訳してある**。

| slug | 英文 | 和訳の現状 |
|---|---|---|
| `bladed-riftseer` | `Units with true sight can attack objects with stealth.` | ✅ 「ステルスを持つオブジェクト」 |
| `peer-beyond` | 同上 | ✅ 「ステルスを持つオブジェクト」 |
| **`extraction-incision`** | `This attack can target objects with stealth.` | ⚠️ **「ユニット」のまま** |

## 4. 前提と制約（⚠️ ここを外すと静かに壊れる）

### 4-1. ⚠️ ⭐ `terms` の `jp`（中核語「トゥルーサイト」）は変えない

⭐ **中核語はハイライトと用語解説のゲートそのもの**（2026-08-30 の案C′）。
**変えると、その用語の解説とハイライトがまるごと消えうる**。⭐ **直すのは `desc` だけ。**

- ⭐ **実測した中核語**: `true sight` → **「トゥルーサイト」**／`stealth` → **「ステルス」**
- ⭐ **中核語の重複は無い**（135キー全部ユニーク＝実測）。**同じ見出しが2行並ぶ事故は起きない**

### 4-2. ⭐ `matchedTerms()` は OR ゲート（⚠️ 破壊試験の期待値を書く前に読むこと）

`scripts/build-card-pages.mjs` の `matchedTerms()` は **「英語 ∪ 訳文」** で、
**最後に `return found.concat(extra);` と、①英語ゲートで採ったものを無条件に残す**（実測で読んだ）。

⭐ **だからトゥルーサイトは「どちら側か」が2つに割れる**:

| 群 | 枚数 | 用語解説の行は何に支配されるか |
|---|---:|---|
| 英語効果文に `true sight` が在る | **83** | ⭐ **英語ゲート**。⚠️ **訳文をどう崩しても用語解説の行は消えない**（消えるのは本文のハイライトだけ） |
| 英語に無く、**訳文だけ**にトゥルーサイトが在る | **2**（`corhazi-arsonist` / `shifting-mirage`） | ⭐ **訳文ゲートのみ**。崩すと**用語解説の行も消える** |

⚠️ ⭐ **`extraction-incision` は英語ゲート側**（英語に `True Sight` が在る）。
⭐ **＝ 今回の訳文の修正では、用語解説の行もハイライトの個数も1つも動かない**（実測＝§7 V7）。

### 4-3. ⭐ 「ユニット」「オブジェクト」は中核語ではない

⭐ **実測**: 135キーの中核語のうち、`ユニット`／`オブジェクト` を含むのは
**`non-champion object link` →「ノンチャンピオンオブジェクトリンク」の1件だけ**で、これは長い語なので
「ステルスを持つオブジェクトを対象にできる」には一致しない。

⭐ **＝ ユニット→オブジェクト の置換で、ハイライトが増えも減りもしない**（実測で裏取り済み）。

### 4-4. ⭐ 残り23枚と文面が食い違って見えるのは**意図どおり**

⚠️ ⭐ **実装・レビューが「用語集は オブジェクト なのに、23枚のカード本文は ユニート のままで矛盾している」と
報告してきそうな点なので先に書く。**

⭐ **公式自身がいま両方を併記している状態**（`objects` 3枚 / `units` 23枚）。
**カード本文のリマインダーは「そのカードに印刷されている文」なので、カードごとに現行英文へ合わせるのが正**。
**用語集はキーワード一般の説明なので、公式が広げた側（オブジェクト）に合わせる**。
⭐ **`terms["stealth"].desc` が既に「このオブジェクトは…」と書いてある**（実測）ので、
**用語集の内部整合はむしろ良くなる**。
