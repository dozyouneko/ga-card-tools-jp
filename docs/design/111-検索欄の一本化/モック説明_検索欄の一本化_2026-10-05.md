## 1. 上げ方（⚠️ 3000番）

⚠️ ⭐ **`.devcontainer/devcontainer.json` の `forwardPorts` は `[3000]` の1つだけ**なので、
**3000番以外はユーザーのブラウザに届かない**（コンテナ内からは `curl` も Playwright も 200 を返すので、
渡す側だけを見ていると正常に見える）。

```bash
cd /workspaces/claude-test-vsc
npm run dev                 # 既定で 3000番（scripts/serve.mjs）
```

⚠️ **`PORT=` を付けないこと。** 付けたらユーザーには届かない。

### 開くURL

```
http://localhost:3000/docs/design/111-検索欄の一本化/モック_検索欄の一本化_2026-10-05.html
```

⚠️ パスに日本語が入っているのでコピペで開くこと（ブラウザが自動でエスケープする）。

### 止め方

```bash
PID=$(ss -ltnp 2>/dev/null | grep ':3000' | grep -oP 'pid=\K[0-9]+' | head -1); [ -n "$PID" ] && kill "$PID"
```

⚠️ **`pkill -f "scripts/serve.mjs"` は使わない**（他セッションのサーバーと自分のシェルを巻き添えで落とす）。

## 3. ⭐ 触ってほしいところ（この順で）

| # | 操作 | 見てほしいこと |
|---|---|---|
| **M1** | §1 を眺める | **1欄の placeholder が長すぎないか**。「カード名・効果テキストをまとめて検索（英語 / 日本語）… 例: lorraine draw」で読めるか |
| **M2** | §2 の 375px 枠を見る | **スマホで欄が1つになったときの見え方**。⭐ 最長入力（`"Lorraine, Honed Operative" "buff counter"`）でも**はみ出さない**こと |
| **M3** | §3 で「lorraine」を押す | **13件**。⭐ 各カードの下に「`"lorraine"` → 名前／効果／裏面」と**どこで当たったか**が出る。⚠️ ⭐ **`Capacitance X Psycho` のように「名前にロレインが無いカード」が混ざるのが D2 の帰結**。これを**許容できるか**を見てほしい |
| **M4** | §3 で「lorraine draw」を押す | **2件**。⭐ **名前に lorraine・効果に draw** のように**場所をまたいで AND** になっていること |
| **M5** | §3 で「"buff counter"」と「buff counter（引用符なし）」を押し比べる | ⭐ どちらも 157件。**引用符が必要になるのは `on hit`・`end of turn` のような語**（§4 の表） |
| **M6** | §3 で「card（重い例）」を押す | ⚠️ **「読み込み中 n/50 ページ…」が出て約40秒かかる**。⭐ **そのあと `cards` に打ち換えると即座に出る**（キャッシュ）。**この待ちを許容できるか**を見てほしい |
| **M7** | §3 で「ab（2文字＝検索しない）」を押す | 「英語で検索するときは3文字以上入力してください。」。⭐ **公式APIを1回も叩かない**（リクエスト 0件と出る）。⚠️ **英語2文字の検索ができなくなる**ことを許容できるか |
| **M8** | §5 の表を見る | ⭐ **用語リンクを引用符つきにする**という判断（設計書 §4-3）に同意できるか |

## 4. ⚠️ モックで**できないこと**

| できないこと | 理由 / 本番ではどうなるか |
|---|---|
| **日本語検索** | モックは訳データ（`data/tl-names.json` / `data/tl-effects.json`）を読み込んでいない。⭐ **本番は全部ローカル照合＝0リクエストで即答**。件数は §4 の日本語の表にある |
| **絞り込み（チップ・エキスパンション・フォーマット）との併用** | モックに絞り込みUIを載せていない。⭐ **本番では絞り込みを併用するほど速くなる**（`draw` ＋ タイプ=チャンピオンは 3リクエスト・1.76秒＝§6） |
| **並び替え** | モックは名前順（昇順）に固定。⭐ 本番はレアリティ順・数値4項目もローカルで並べる（比較器は設計書 §5-5 で実測確定） |
| **デッキ構築ツールの見た目** | ⭐ **実物確認（②）に委ねる**（設計書 §11 の U7〜U9）。ログインが要るのでモックでは出せない |
| **「もっと見る」** | モックは先頭60件を並べるだけ。本番は 50件ずつ |
