## 症状

新セット **DTR Alter**（Distorted Reflections Alter Edition・prefix は**空白入りの `"DTR Alter"`**・`release_date` **2026-10-16**）が公式APIに入った。
`data/translations.js` の **`meta.sets` に未登録**のため、CLAUDE.md「新セットが公式APIに入ったら `meta.sets` に手で追記する」（#40・SP4 で約1か月放置した型）にそのまま当たっている。

⚠️ **いま `npm run validate` は緑だが、それは空回りしている。**
`meta.sets` の検査は **`cards/index.html` の `/sets/<slug>/` リンクを正**にしており、まだ `build:cards` を回していないので `/sets/dtr-alter/` が生えていない。

### ⭐ `build:cards` を回すと exit 1 になる（**実測で再現済み**）

`git archive HEAD` で作業ツリーに触れない複製を2つ作り、`GA_SNAPSHOT_MAX_AGE_MIN=0` でスナップショットを固定して測った。

- **修正なしで `build-card-pages.mjs`** → 完走サマリに `⚠ meta.sets 未登録のセット: 1件 (DTR Alter)` が出る。
  続けて `node scripts/validate.mjs` → **exit 1**:

  ```
  top set links up to date — index.html に /sets/ リンク 64本

  UNREGISTERED SETS (meta.sets):
    - セットページはあるが data/translations.js の meta.sets に無い: dtr-alter
  ```

- **`meta.sets` に1行足してから同じ手順** → 警告行が消え、`meta.sets covers all sets — 64件`・**exit 0**。
