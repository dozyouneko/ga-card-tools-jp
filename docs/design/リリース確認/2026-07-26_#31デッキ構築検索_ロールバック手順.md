## ロールバック判断の基準

**即ロールバック**:

- **トップページ**の絞り込みUIが崩れる(チップが素のリスト・AND/ORが効かない・レイアウト破綻)
- デッキ構築で**検索できない / 結果が出ない / カードを追加できない**
- どちらかの画面でJSエラーが継続的に出る

**ロールバックしない**(記録して個別対応):

- スマホ幅でチップが縦を使う → #21 の範囲
- 絞り込み件数バッジの見た目 → 表示のみ
- チップ変更で再検索しない(明示的な🔍検索ボタンで走る) → 設計判断として承認済み
