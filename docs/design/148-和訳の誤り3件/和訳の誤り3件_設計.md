## 1. #148 shadowstrike — 現状の実測

公式APIが `title: "Errata"` の裁定2件（`date_added: "2026-10-20"`）を追加し、**英語 `effect` にも反映済み**。

| | 英語（公式API・2026-10-26） | 和訳（`data/tl/p25.js`・現在） |
|---|---|---|
| ① | `As long as Shadowstrike was **prepared**, Shadowstrike get **+X** [POWER].` | ⚠️ `「シャドウストライク」は**+X**[パワー]を得る。`（**条件が丸ごと無い**） |
| ② | `[Class Bonus] As long as Shadowstrike was **prepared**, it has **unblockable.**` | ⚠️ `…が**プレパレーション**されていた**なら**、…`（＝ `If` 相当） |

- ⚠️ ⭐ **向きは安全側ではない。** ①は日本語だけ読むと「常に +X パワーを得る」と誤読する
  （#34 のシーズン禁止・#138 の `legality` の窓は「使えるのに使えないと出す」＝安全側だったが、**これは逆**）
- ⚠️ ⭐ **この状態が 2026-10-26 時点の本番に出ている**（`cards/shadowstrike/index.html`）
- ⭐ **#120 のスコープ外**（#120 は「公式APIの `effect` に**未反映**な 56件/54枚」。本件は**反映済み**の側）

### 1-1. 訳文の先例（⭐ 実測で確定）

公式APIが `As long as … was prepared` を返すカードは **3枚**:

| slug | 英語 | 和訳 | |
|---|---|---|---|
| `find-the-lost` | `As long as CARDNAME was prepared, it has unblockable.` | `このカードが**プレパレーション**されていた限り、それは**アンブロッカブル**を持つ。` | ⭐ **② と同一の英文** |
| `strike-from-the-mist` | `As long as CARDNAME was prepared, it can't be intercepted.` | `…が**プレパレーション**されている限り、それはインターセプトされない。` | |
| **`shadowstrike`** | 上表 | ⚠️ ①無条件・②`されていたなら` | **これだけ外れている** |

- ⭐ **英語に `As long as` を含むカードは 339枚で、全枚数が和訳済み。**
  ⭐ **和訳に `限り` も `かぎり` も現れないのは `shadowstrike` の1枚だけ**（`限り` 280 / `かぎり` 58 / 該当なし 1）
  ＝ ⭐ **既訳の慣例から外れている唯一のカードで、慣例は漢字の `限り` が多数派**
- ⭐ `If CARDNAME was prepared` 側は **22枚が例外なく `…されていたなら`**＝
  ⭐ **`なら`（If）と `限り`（As long as）の書き分けが既訳に確立している**ので、
  **②の `なら` → `限り` は「言い換え」ではなく「意味の修正」**

  ⭐ **コメントなので表示には出ない。触らない**（`スート` 単独はここだけ）

### 3-2. ⭐ `meta.subtypes` の訳語は `subtype-hl`（効果文の強調）も支配している

⚠️ ⭐ **これは起票時に見落としていた依存で、変更の効果がいちばん大きい箇所**。

`scripts/build-card-pages.mjs` と `shared/js/card-detail.js` は、
**`meta.subtypes` の訳語が効果文に現れたら `<span class="subtype-hl">` で強調する**。
いまは `meta.subtypes.SUITED = "スーツ持ち"` なので、

- ⚠️ **効果文の `スーテッド` は強調されない**（47箇所すべて素のテキスト）
- ⚠️ **強調されるのは `スーツ持ちオブジェクト` の1箇所だけ**（`bleu-ace-of-diamonds`）

⭐ **実測: `subtype-hl">スーテッド<` は base 0 → after 68箇所 / 50ページ**
（`subtype-hl` の総数は **181 → 248**）。
⭐ **＝ 一本化すると「キーワードがサブタイプとして強調される」という本来の表示が初めて効く**。

### 3-3. どちらに寄せるか（⭐ 決定）

⭐ **`スーテッド` に寄せる。** 根拠3つ:

1. **多数派**（47 vs 25）で、**5ファイルにまたがる**（`スート`系は `rdo.js` 1ファイルの外れ値）
2. `meta.subtypes` の既存の流儀と合う（`SPIRIT: "スピリット"` のように**音写を採っている前例がある**）
3. ⭐ **`Suited` はサブタイプ名**なので、サブタイプ行と効果文で同じ字面になることに意味がある（§3-2）

⚠️ **`スーツ持ち` を採らない理由**: ⭐ **トランプの「スート」を「スーツ（衣服）」と誤読させる**うえ、
**効果文側の47箇所を書き換える側になり、変更が2倍以上になる**。
