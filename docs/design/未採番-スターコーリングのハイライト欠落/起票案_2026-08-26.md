## タイトル（案）

```text
キーワード Starcalling（スターコーリング）で用語ハイライトと用語解説が出ない（10枚）
```

## 本文（案）

### 症状

**10枚のカードで、効果文の「スターコーリング」がハイライトされず、用語解説にも出ない。**

| slug |
|---|
| `arisanna-astral-zenith` / `astra-sight` / `cometfall` / `cosmic-bolt` / `cosmic-focus` |
| `lunar-seer` / `potion-infusion-starlight` / `scry-the-stars` / `stellar-bloom` / `the-elysian-astrolabe` |

### 原因（2026-08-26 実測・スナップショット2,494枚と `data/tl-effects.json` を突き合わせ）

⚠️ **表記ゆれではない。辞書のキーと日本語の中核語がずれている。**

1. 10枚の英語原文にあるのは動詞 `starcall` ではなく、**キーワード能力 `Starcalling`**
   （例: `**Starcalling** — (2) *(As you're looking at this card while glimpsing…)*`）
2. `matchedTerms()` は **`\b` + キーの前方一致**なので、**キー `starcall` が `Starcalling` に当たる**
3. その `terms["starcall"]` の `jp` は **「スターコール（Starcall）」** で、中核語は「**スターコール**」
4. しかし日本語訳は「**スターコーリング**」なので、`highlightTerms()` が中核語を見つけられず
   **ハイライトも用語解説も出ない**（⚠️ **fail-open なので画面は壊れず、黙って出ないだけ**）

⭐ **`starcall` / 「スターコール」という登録自体は正しい。**
`starcalled` → 「スターコールされた」等、**動詞として既訳6箇所で実際に使われている**
（`data/tl/{dtr,mrc,rdo,rdo-ext}.js`）。**抜けているのはキーワード `Starcalling` のほう**。

### 直し方の見当と、⚠️ 設計時に確かめること

**`terms` に `"starcalling"` を追加する**のが素直（`jp: "スターコーリング（Starcalling）"`）。
ただし**前方一致のため `Starcalling` は `starcall` にも当たり続ける**ので、次を実測してから決めること:

1. ⭐ **ハイライトは動くはず**（コードを読んだ限り）。`highlightTerms()` は中核語を
   **文字数の降順に並べて選択肢の正規表現**を作るため、「スターコーリング」(8字) が
   「スターコール」(6字) より先に当たる。⚠️ **実駆動で確認すること**
2. ⚠️ **用語解説には2件（スターコール＋スターコーリング）が並ぶ。**
   ⭐ **これを許容するか、片方に寄せるかが本issueの設計判断**
3. ⚠️ ⭐ **`check-terminology.mjs` の報告は、キーを足しても消えない。**
   このツールは**キーごとに**「ENにキーがある → JP訳に中核語がある」を見るため、
   キー `starcall` の側で**同じ10件を報告し続ける**。
   → **ツール側も「より長い別のキーが同じ箇所に当たっていれば見逃す」形に直さないと、
   報告0件にならない**（⚠️ **今回のような本物の欠落を、次に埋もれさせる原因になる**）

### 対象外（誤検出）

`check-terminology.mjs` の既存報告のうち **`charge` × 1（`charge-the-soul`）は不具合ではない**。
英語原文の `charge` は**そのカード自身の名前**（`load Charge the Soul into…`）で、
JP訳は日本語のカード名に置き換わるため中核語「チャージ」が現れないだけ。**本issueでは触らない。**
⭐ ただし上記3のツール改修を行うなら、**カード名由来の誤検出も併せて抑制できるかを検討する**。
