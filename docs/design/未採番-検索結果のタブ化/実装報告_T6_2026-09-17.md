### 1-1. 変更の中身（`31a98522`・⭐ **作業は1関数**）

```js
function scrollTabIntoView(tab) {
  if (!tab || !tab.item || !el.edTabsScroll) return;
  const box = el.edTabsScroll;
  box.scrollLeft += tab.item.getBoundingClientRect().left - box.getBoundingClientRect().left;
  updateTabsFade();
}
```
