### 2-1. ⭐ 再現した（ユーザーの報告と一致）

**5タブ（検索1〜検索5）・箱は `clientWidth 127 / scrollWidth 472 / maxScroll 345`。**

  ⭐ **右端だけ正しく見えるのは、スクロール量がブラウザに `maxScroll` でクランプされて偶然合っているから**。
- ⚠️ ⭐ **リロード復元でも同じ**: `active = 検索4` で復元すると、**選択中のタブが左に 59px はみ出した状態**で始まる（`alignGap -59`）。
- ⚠️ **開始位置によって飛び先が変わる**（`scrollLeft 0` から押すと 195・右端から押すと 232）。**どちらも誤り。**

### 2-2. ⭐ 原因（⚠️ **進行役の仮説は正しかった。数値で確定した**）

`scrollTabIntoView()` が **`tab.item.offsetLeft` を「箱の内容座標」として使っている**が、

- ⚠️ ⭐ **`.tabs-scroll` は `position: static`** なので、**`.tab-item` の `offsetParent` は `<body>`**（実測）。
- ⚠️ ⭐ **`offsetLeft` には固定タブ（🃏/📊）と帯の padding が入っており、実測で `box.offsetLeft = 232px` ずれる。**
- ⭐ **つまり「箱の中で 0 の位置」を 232 と思い込んでいる**＝ **常に右へ寄りすぎる**（`maxScroll 345` の 232＝**約3番目**）。

### 2-3. ⭐ 直したときの期待値（**rect の差で寄せる案**を当てて実測）

`box.scrollLeft += item.getBoundingClientRect().left - box.getBoundingClientRect().left`

| 押したタブ | `scrollLeft` | 左端とのズレ | 完全に見えるか |
|---|---|---|---|
| 検索1 | **0** | **0** | ✅ |
| 検索2 | **95** | **0** | ✅ |
| 検索3 | **191** | **0** | ✅ |
| 検索4 | **286** | **0** | ✅ |
| 検索5 | **345**（クランプ） | 37 | ✅（⭐ **ユーザーの「その場合は一番右でもよい」**） |

- ⭐ **箱の左端は 📊統計 の右端の 17px 右**（区切り線と gap のぶん）＝ **「統計タブの横」に来る。**
- ⭐ **リロード復元（`active=検索4`）でも `scrollLeft 286`・左端一致・完全に見える。**
- ⭐ **1440px では `maxScroll = 0` なので何も動かない**（5タブとも収まる＝回帰の心配なし）。

### 2-4. ⭐ 呼ばれる経路は5つ、通る関数は1つ（実測）

**押す／🔍で新規／キーボード ←→／リロード復元／× で隣へ移る** — **すべて `selectSearchTab()` → `scrollTabIntoView()`**。
⭐ **＝直すのは1か所**。**新しいタブ（右端）はクランプで右端に見える**ので、**§4-2「新しいタブは右端に作る」と矛盾しない**（実測で確認）。

## 3. ⭐ 決めた仕様（設計書 §4-3-1）

1. ⭐ **検索タブが選ばれたら、そのタブの左端を「スクロール箱の左端」（＝📊統計 のすぐ右）に合わせる。**
2. ⭐ **右端側で寄せ切れないタブは最大スクロール位置で止める**（＝一番右に見える）。
3. ⭐ **寄せ方は5経路とも同じ。**
4. ⚠️ ⭐ **アニメーション（`smooth`）は今回決めない**——**2回目の実物確認で、ページの送り（§8-7）と一緒に聞く**（§10-5-3 の B）。

⚠️ **実装上の禁止**（設計書 §4-3-3）:

- ❌ **`offsetLeft` を使う**（原因そのもの）／❌ **`.tabs-scroll` に `position: relative` を足して `offsetLeft` を使う**
  （⭐ **CSS と JS にまたがる暗黙の依存を新しく作る**＝§8-4-3 で消したばかりの型。**rect 差なら CSS に依存しない**）。
- ❌ **`element.scrollIntoView()`**（⚠️ **祖先＝ページまで縦に動きうる**ので §8-7 と衝突する。**動かすのは `#ed-tabs-scroll` の `scrollLeft` だけ**）。
