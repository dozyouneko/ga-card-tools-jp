# 派生issueの起票案 — アクセント色が `rgba(217,164,65,…)` の直値でページCSSに散っている

- 出どころ: **検索結果のタブ化** の **T3 レビュー S-4**（`レビュー判定_T3_2026-09-16.md`）と **T4 レビュー S-4 / 実装報告 §6 の1**（2026-09-17）
- ⚠️ **本体タスクでは直さない**（範囲が `shared/` と別ページに跨るため＝**V21 の範囲外**）。設計書の申し送り **§11-10**

## 1. 症状

`--accent`（`#d9a441` ＝ `rgb(217,164,65)`）と**同じ色を手で書いた `rgba(217,164,65,…)`** が、ページCSSに散っている。
⚠️ ⭐ **トークンを変えた日に、これらだけが古い色のまま残る**（**色がちぐはぐになるが、どこにも警告は出ない**）。

- ⭐ **`npm run validate` の `shared css tokens in sync` は気づけない**——あれは **`var(--…)` の参照と定義の突き合わせ**で、
  **リテラルで書かれた色は見ていない**（⚠️ **緑のまま**）。

## 2. ⭐ 実測した範囲（2026-09-17・⚠️ **起票時に数え直すこと**）

⚠️ ⭐ **レビューと実装報告は「デッキ構築の2か所」と書いているが、実際はサイト全体で 4ファイル10か所**だった:

```bash
grep -rn "rgba(217" --include=*.css . | grep -v node_modules | grep -v "^./docs"
```

| ファイル | 箇所 | 中身 |
|---|---|---|
| `style.css`（トップ） | 2 | `#selected-filters`（選択中の条件の背景）／`#selected-filters-list button:hover` |
| `shared/css/filter-chips.css` | 2 | `.fgroup .chip.on` の背景／もう1か所（スマホ帯） |
| `tools/deck-builder/style.css` | 2 | `#s-selected-filters.has-selection`／`#s-selected-filters-list button:hover` |
| `tournaments/tournaments.css` | 4 | `.cat-store`／`tr.top1`／`.rank-badge` ほか |

- ⭐ **検索結果のタブ化 T4 で、条件の箱だけは `color-mix(in srgb, var(--accent) 8%, transparent)` に直した**
  （設計書 §8-4-2 の4）。⚠️ ⭐ **つまり同じ画面の中で「追従する箱」と「追従しない選択中の条件」が並んでいる**。

## 3. 直し方の案

- ⭐ **`color-mix(in srgb, var(--accent) N%, transparent)` に置き換える**（T4 で実績あり・**新しいトークンを足さずに済む**）。
- ⚠️ ⭐ **ページCSSに `:root` を書かない**（`npm run validate` の `:root owners in sync — 4ファイル` が **exit 1**）。
  **トークンを増やすなら `shared/css/tokens.css` の1本に足す**（⭐ **CSSトークンは `:root` 1本だけ**という規約）。
- ⚠️ **見た目が変わらないことの確認は目視では不足**——⭐ **`--accent` を差し替える破壊試験**で、
  **置き換えた箇所が全部追従すること**を見る（T4 の V17-d と同じやり方）。

## 4. ⚠️ 起票前に確かめること（⭐ **起票案は下書きであって確定した事実ではない**）

1. ⭐ **上の `grep` を打ち直して件数を数え直す**（⚠️ **この表は 2026-09-17 の値**）。
2. ⭐ **`--accent` 以外の色（`--accent-2` など）にも同じ直値が無いか**を見る。
3. ⚠️ **`tournaments.css` は `:root` を持つ4ファイルのうちの1つ**なので、**触るときに `:root owners` の検査を壊さないこと**。

## 5. 規模の目安

**小タスク**（置換と破壊試験だけ。⚠️ ただし**4ファイルに跨るので、変更は本番配信物**＝公開判断が要る）。
