## 2. 承認の理由

1. ⭐ **本番に実在した不具合が2件直った**（＝このタスクの目的そのもの）:
   - **P1**: 結果を開いたまま左ペインの条件を変え「もっと見る」を押すと、**別条件の結果が同じ一覧に混ざる**
   - **V22・P5 の再発**: 「もっと見る」で足されるタイルの**絵柄が、検索時ではなく左ペインの「いま」で決まる**
2. **6単位すべてがレビュー合格**で、**差し戻しは T1・T2 の1回だけ**（T3〜T6 は0回）。
   必須基準 M1〜M7 は各判定で表になっており、「未検証」を残したまま合格させた単位は無い
3. ⭐ **ヘッドレスで担保できない範囲を、実物確認2回で消化した**。
   1回目で**実在の症状（タブ帯の寄せ方）を1件検出**し、**「継続」で設計へ戻して T6 として直した**
   ——⚠️ **モックとレビューだけでは出なかった**ので、UIタスクに実物確認工程を挟む運用（CLAUDE.md 締め作業5の例外）が今回も効いた
4. **`npm run validate` は全単位で exit 0**。⭐ **検査①（`onRemoveOne` の配線）の期待値変更**も T2 で同時に通してある
