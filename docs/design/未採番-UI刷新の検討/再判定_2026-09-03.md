## 5. 参考（⚠️ 合否には含めない）

### 5-1. `:has()` の対応状況について

- 検証ブラウザでは `CSS.supports("selector(:has(*))")` が **`true`**。
- ⭐ **未対応ブラウザではセレクタごと無視され、`max-height: 200px` が残る＝修正前の見た目に戻るだけ**で、
  **JS の文言修正（②）は効いたまま**・**落ちない**。実装報告 §8-1 の fail-open の説明は妥当。
- ⚠️ **`:has()` はこのリポジトリで初めて使われた**（`grep` で他に用例なし）。
  ⭐ **CSS の下限ブラウザについて明文の方針が無い**ので、**今後 `:has()` を増やすかどうかは設計担当の判断**。
  ⚠️ **本タスクの合否とは無関係**。

### 5-2. 初回レビューの見落としについて（⭐ わたし自身の反省）

⚠️ **①はわたしが合格を出した実装が作った不具合で、レビューで捕まえられるはずのものだった。**
原因は**「最悪ケース」の定義を「4グループ全開」だけにして、群の内側の展開（＝`＋ すべて表示`）を
含めなかったこと**。⭐ **`.chips-rest` の class が `"chips chips-rest"` である以上、
`.chips` を対象にしたルールは必ず両方に当たる**——**セレクタが当たる要素を数え上げていれば、
操作しなくても気づけた**。

⭐ **再発防止として §6 に「今後このコードを触るときの必須ケース」を残す。**
