## 3. ⭐ 承認の理由

1. ⭐ **「正しさ」の根拠が二重に取ってある。** 英語モードとの全数一致（576通り）だけでなく、
   **参照実装そのものを公式APIの `total_cards` で裏取りしている**（9クエリ全数一致）。
   ⚠️ **両辺が同源では意味が無い**という点をレビューが自覚して潰しており、ここが本判定でいちばん重い
2. ⭐ **ハーネスが空振りでないことの対照実験がある。** 変更前 `1601f925` で同じハーネスを回すと
   **351通りが不一致**になる＝**検査が実際に差を検出できる**ことが示されている
   （⚠️ 全数一致だけを見せられても「何も測っていない」可能性を排除できない）
3. **異常信号を鈍らせていない。** 新規則で落ちる分は `jpBlindDropped` に入り、
   ⭐ **`jpDropped` は新旧同値**。索引の腐り・取得失敗・畳み漏れは**破壊試験3種で従来どおり点灯**した
4. **スコープが最小。** 変更は2ファイル、うち `app.js` は**実行される行が0**
