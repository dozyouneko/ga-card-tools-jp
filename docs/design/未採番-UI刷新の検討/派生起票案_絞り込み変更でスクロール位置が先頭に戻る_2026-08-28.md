絞り込み・並び替えを変更すると、結果の再描画でスクロール位置が先頭に戻る

## 本文（案）

### 症状

カード一覧を途中までスクロールした状態で絞り込み（チップ）や並び替えを変更すると、
**再描画の途中でページが縮み、スクロール位置がページ先頭へ戻る**。

⚠️ **これは新しい不具合ではない**（未採番「スマホの絞り込み導線」の**変更前と完全に同一の挙動**）。
⭐ **ただし同タスクで FAB＋ボトムシートが入り、「スクロールした状態のまま絞り込みを変える」ことが
初めて普通の操作になったため、ここから先は日常的に目に付く。**

### 再現（レビュー担当の実測・390x844）

| 時点 | `window.scrollY` | `document.scrollingElement.scrollHeight` |
|---|---:|---:|
| 変更前（操作開始時） | 1500 | 10,764 |
| 再描画の途中（グリッドが空になる） | **0** | **844** |
| 結果描画後 | **0**（戻らない） | 11,017 |

⭐ **変更前（`663bcc84^`）と変更後で `y0=1500 → mid 0 → end 0` が完全に一致**することを、
レビュー担当が3100/3101の並走で確認済み（回帰ではない）。

### 原因（コードの所在）

`app.js` の検索コントローラの `onStart(reset)`（`app.js:100` 付近）が、
**新しい結果を取得する前にグリッドを空にする**。

```js
if (reset) {
  shownSlugs.clear();
  el.grid.innerHTML = "";      // ← ここでページ高さが 10,764 → 844 に縮む
  el.loadMore.hidden = true;
}
```

⚠️ **明示的に `scrollTo(0, 0)` している箇所は無い**（`grep -n "scrollTo\|scrollIntoView" app.js` は0件）。
**ページが縮んだ結果、ブラウザが `scrollY` を上限（=0）へクランプしているだけ**で、
結果が描画されて高さが戻っても**位置は 0 のまま**になる。

### ⚠️ 先に決めるべきこと（＝設計判断が要る理由）

**「必ず位置を保つ」が正解とは限らない。** 操作の種類で望ましい結果が違う:

| 操作 | 結果集合 | 位置を保つべきか |
|---|---|---|
| **並び替えだけ**を変えた | **同じ**（順序だけ変わる） | ⭐ **保つ意味が薄い**（同じ位置に別のカードが来る）。むしろ**先頭を見せるほうが自然**とも読める |
| 絞り込みを**広げた／狭めた** | 変わる | 位置を保っても意味のある内容が見えるとは限らない |
| ⚠️ **何も変えずにシートを閉じた** | 変わらない | ⭐ **保つのが正しい**（**現状も保てている**——未採番タスクの実測で 1500 のまま） |

⭐ **したがって「クランプで偶然0になる」現状を、意図した挙動に置き換えるのが本質**。
候補（いずれも未検証・設計工程で実測して決める）:

1. **グリッドの高さを再描画中だけ維持する**（`min-height` を退避）→ クランプ自体を起こさない
2. **意図的に一覧の先頭へ寄せる**（`#grid` の上端へスクロール）→ **「先頭に戻った」ことが分かる**動きにする
3. **結果件数が変わらない操作（並び替えのみ）に限って位置を保つ**

⚠️ **2 を採るなら「ページ最上部」ではなく「一覧の先頭」にする**——スマホでは
ヘッダと `.controls` を再度スクロールさせられるのが今の不満そのもの（元タスクの起点）。

### ⚠️ 実装時の注意（調査済みの落とし穴）

- ⚠️ **JPモード・数値ソートは取得が長い**（絞り込みなしで **45リクエスト・約19秒**）。
  この間グリッドは空なので、**「取得完了後に位置を復元する」だけの実装は体感が悪い**（19秒間0のまま）
- ⚠️ **シートが開いている間は `body.no-scroll` が効く**ので、`window.scrollTo()` は動かない。
  **位置の操作はシートを閉じた後**に行う必要がある
- ⚠️ 検証は **`npm run dev`** で足りる（`_headers` に依存しない）。
  ⚠️ Playwright の `addStyleTag` は meta CSP（`style-src 'self'`）に阻まれるので、
  スタイルを差し替えて測るときは **`element.style.setProperty()`（CSSOM）**を使う
