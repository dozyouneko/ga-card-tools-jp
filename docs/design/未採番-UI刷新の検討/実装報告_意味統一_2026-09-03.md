- 変更ファイルは **2つだけ**（`git -c core.quotepath=false show --name-only` で確認）:
  - `shared/js/card-search.js` — 判定の中核

### 変更の中身（設計書 §4 の統一規則）

```
① 版の候補集合 E を作る（editionSetOf）
     エキスパンション絞り込みが有効 → E = {e | prefix(e) ∈ P}
     無効                          → E = 全版
② その E の中でレアリティを判定する（rarityMatchesIn）
     OR  指定 → ∃e∈E: rarity(e) ∈ R      … 公式API（prefix + rarity）と完全一致
     AND 指定 → ∀r∈R: ∃e∈E: rarity(e) = r … 「その版群の中で両方刷られている」
```

| 変えたところ | 内容 |
|---|---|
| `haveOf()` | ⭐ **削除**。版からレアリティを組み立てる役目は `editionSetOf()`＋`rarityMatchesIn()` に移した |
| `matchesMulti()` | 版レベルの項目（`field === null`）は通さない。⚠️ **万一通っても `true`（＝絞らない）に倒す**（fail-open） |
| `matchesActiveFilters()` | 一般ループで **`isIndexBlind()` を常に読み飛ばし**、末尾で ①→② を評価する |
| `matchesAndFilters()`（英語モードのAND後段） | 同じく ②を **E の中で**評価する |

### ⭐ 壊してはいけない4つ（指示の表）への対応

| # | 守るもの | どう守ったか |
|---|---|---|
| **P2** | JPモードで `metaMatches()` がレアリティを読み飛ばす | ⭐ **`metaMatches()` は1行も変更していない**。`isIndexBlind(m)` で `continue` する既存の形のまま（M-V6 の破壊試験で生存を確認） |
| **D-1** | 索引で判定できない絞り込みが有効なら `jpApprox` | ⭐ **`indexBlindActive()` は無変更**。`MULTI.filter(isIndexBlind)` から導かれる形も無変更（M-V7） |
| **D-2** | 索引の盲点だけが原因の除外は `jpDropped` に数えない | ⭐ **`skipIndexBlind` の意味を「レアリティを完全に無視／E の絞り込みは残す」に保った**（M-V6） |
| **P5** | `preferredArtIndex()` が絞り込みに一致する版を選ぶ | ⭐ **`app.js` の当該関数は無変更**（コメント1行のみ）。M-V8 で4面を再確認 |

⚠️ **`isIndexBlind()`（`field === null`）の定義は変えていない。** P2・D-1・D-2 の唯一の出所である
という位置づけもそのまま（むしろ `matchesActiveFilters()` / `matchesAndFilters()` の両方が
この関数から「版レベルかどうか」を導くようになり、参照箇所が3→5に増えた＝ハードコードは1つも足していない）。

## 5. 設計書からの逸脱と根拠

| 項目 | 設計書 | 実装 | 根拠 |
|---|---|---|---|
| 「レアリティを `MULTI` の一般ループから外す」 | §4 実装の要点 | ⭐ **そのとおり実装した**（`matchesActiveFilters` / `matchesAndFilters` の両方で `isIndexBlind()` を読み飛ばし、末尾で2段階評価）。⚠️ **`MULTI` の配列自体からは外していない** | ⭐ **外すと `isIndexBlind()` の定義が消え、P2・D-1・D-2 の出所が無くなる**。設計書も「`isIndexBlind()` の定義は維持する」と明記しているので、**「一般ループから外す」＝「配列から消す」ではない**と解釈した |
| `haveOf()` の削除 | 言及なし | ⭐ **削除した**（呼び出し元が無くなるため） | 残すと**誰も呼ばない分岐**になり、次に読む人が「レアリティは版を問わず判定される」と誤読する。⚠️ 代わりに `matchesMulti()` に **fail-open のガード**（`if (!field) return true;`）を置いた |
| `app.js` の変更 | ⚠️ 「PC左ペイン／チップ絞り込み欄のコードを動かさない」（指示） | ⭐ **コメント1行のみ**（`haveOf()` への参照を書き換え） | 消した関数を指すコメントを残せない。⚠️ **実行される行は1行も変えていない**（`git diff` で確認可能） |
