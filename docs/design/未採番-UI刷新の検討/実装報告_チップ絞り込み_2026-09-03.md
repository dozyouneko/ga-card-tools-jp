### 1-1. 状態管理の実装（設計書 §5）

⭐ **`.chips-rest` の表示状態を書く「4人目」になる**ため、次の形にした:

```
clearChipFilter()  … 入力・件数・チップの hidden を素に戻す
                     ⚠ restChips.hidden はここでは触らない（reset / setValues の既存処理に任せる）
applyChipFilter()  … input イベントの唯一の入口。文言は syncMore() だけが書き、件数は .cfhint に書く
```

| 仕様 | 実装 |
|---|---|
| **S-1** | `restBeforeSearch` に**検索を始める直前の `restChips.hidden`** を退避し、入力が空に戻ったら書き戻す。空の間は `null` に戻すので、次の検索でまた取り直す |
| **S-2** | 一致件数は **`.cfhint`** に書く。`syncMore()` が書く `.more .hint` は触らない |
| **S-3** | `details.reset()` の先頭で `clearChipFilter()` |
| **S-4** | `details.setValues()` の先頭で `clearChipFilter()`（既存の「隠れ側なら展開する」処理はそのまま） |
| **S-5** | S-1 の帰結として自動的に満たす（開いていたら開いたまま。W6 で両方向を実測） |
| **C-A** | 検索中は `restChips.hidden = false` にし、判定対象は `details.querySelectorAll(".chip")`（157種全部） |
| **C-B** | `c.hidden = !(hit || box.checked)` |
| **C3** | `input` は `type="search"`。`details` の `change` ハンドラは `e.target.type !== "checkbox"` で弾くので**再検索は走らない** |
| **C4** | `keydown` で `e.key === "Escape"` かつ **`cfInput.value` が空でないときだけ** `stopPropagation()` して消す |
| **C5** | `aria-label="サブタイプの選択肢を絞り込む"`。⭐ **`aria-live` は付けない** |
