［クラスボーナス］［レベル6以上］そのアライがこのターンに次に行う攻撃は+4[パワー]を得る。（この効果は、あなたのチャンピオンのクラスがこのカードのクラスと一致し、かつあなたのチャンピオンがレベル6以上である場合にのみ適用する。）

効果（英語原文）

Wake up target ally.

[Class Bonus] [Level 6+] That ally's next attack this turn gets +4[POWER]. (Apply this effect only if your champion’s class matches this card’s class and only if your champion is level 6 or higher.)

このカードの用語
