効果（日本語）

各プレイヤーのリコレクションフェイズの開始時に、スタティックカウンターが1個以上置かれている対象のオブジェクトにスタティックカウンターを1個置く。

効果（英語原文）

At the beginning of each player's recollection phase, put a static counter on target object with one or more static counters on it.

フレーバーテキスト

高電圧コンデンサ。最も御しがたいアーケインすら蓄えることができる。

このカードの用語

  • スタティックカウンター（static counter）アーケインエレメントのユニットが戦闘ダメージをオブジェクトに与えるとき、これを1個取り除いて、そのダメージを受けたオブジェクトにさらに1点のダメージを与えられる。
