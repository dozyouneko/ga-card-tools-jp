効果（日本語）

ソードウェポンリンク （このオブジェクトは、対象の剣ウェポンにリンクした状態で場に出る。リンクが解除された場合、このオブジェクトをサクリファイスする。）

登場時： リンクしたウェポンに耐久カウンターを1個置く。その後、そのウェポンにスタティックカウンターが1個以上置かれているなら、「ジョビアン・ヒルト・Xウルトラ」にスタティックカウンターを2個置く。

リンクしたウェポンは+2[パワー]を得る。

効果（英語原文）

Sword Weapon Link (This object enters the field linked to target Sword weapon. If the link is broken, sacrifice this object.)

On Enter: Put a durability counter on linked weapon. Then if that weapon has one or more static counters on it, put two static counters on Jovian Hilt X Ultra.

Linked weapon gets +2[POWER].

このカードの用語

  • 登場時（On Enter）そのカードが場に出たときに誘発する効果。
  • サクリファイス（Sacrifice）自分のオブジェクトをコストとして墓地へ送る行為。
  • 耐久カウンター（durability counter）ウェポン等に置かれ、その耐久値を表すカウンター。攻撃や効果で減り、無くなると破壊される。
  • リンク（Link）対象のオブジェクトをリンク先として場に出る能力。リンク先を失うと、このオブジェクトはサクリファイスされる。リンク先の種類に応じて「ユニットリンク」「チャンピオンリンク」「ウェポンリンク」などと表記される。
  • ソードウェポンリンク（Sword Weapon Link）対象の剣ウェポンにリンクした状態で場に出るリンクの一種。リンクが解除された場合、このオブジェクトをサクリファイスする。
  • スタティックカウンター（static counter）アーケインエレメントのユニットが戦闘ダメージをオブジェクトに与えるとき、これを1個取り除いて、そのダメージを受けたオブジェクトにさらに1点のダメージを与えられる。
