効果（英語原文）

Ally Link

Link Shield (If linked object would be destroyed, remove all temporary damage from it and destroy this object instead.)

On Enter: Draw a card, then discard a card.

このカードの用語

  • 登場時（On Enter）そのカードが場に出たときに誘発する効果。
  • アライリンク（Ally Link）登場時に自分のアライ1体とリンクし、そのアライを参照する効果を持つファンタジア。
  • リンク（Link）対象のオブジェクトをリンク先として場に出る能力。リンク先を失うと、このオブジェクトはサクリファイスされる。リンク先の種類に応じて「ユニットリンク」「チャンピオンリンク」「ウェポンリンク」などと表記される。
