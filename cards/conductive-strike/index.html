効果（日本語）

「伝導の一撃」は+X[パワー]を得る。Xは、あなたがコントロールする、スタティックカウンターが1個以上置かれているオブジェクトの数。

［クラスボーナス］ ヒット時： (2)を支払ってよい。そうしたなら、あなたがコントロールする各アーケインエレメントのオブジェクトにスタティックカウンターを1個置く。

効果（英語原文）

Conductive Strike gets +X[POWER], where X is the amount of objects you control with one or more static counters on them.

[Class Bonus] On Hit: You may pay (2). If you do, put a static counter on each arcane element object you control.

このカードの用語

  • クラスボーナス自分のチャンピオンのクラスが一致するとき追加効果／コスト軽減を得る。
  • ヒット時（On Hit）この攻撃がダメージを与えたときに誘発する効果。
  • スタティックカウンター（static counter）アーケインエレメントのユニットが戦闘ダメージをオブジェクトに与えるとき、これを1個取り除いて、そのダメージを受けたオブジェクトにさらに1点のダメージを与えられる。
