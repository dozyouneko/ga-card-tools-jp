効果（英語原文）

X must be greater than 0.

On Enter: Misty, the Joker's base reserve cost becomes X.

On Death: You may put a Suited ally card with reserve cost X or less from your hand or memory onto the field. If you do, draw a card into your memory.

裁定（2件）

※裁定は英語原文です。

  • 裁定2026-10-10

    If X is not determined, it is treated as 0 for effects that reference Misty's reserve cost. This includes Misty's own on enter ability.

  • 裁定2026-10-10

    Misty's on enter ability can set Misty's reserve cost to 0, because it is setting her base reserve cost directly, rather than determining a value for X.
