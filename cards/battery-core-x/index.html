効果（日本語）

ハインダード （このオブジェクトはレスト状態で場に出る。）

[レスト]、「バッテリーコアX」を追放する： このターン、対象のアライがチャンピオンに対して行う次の攻撃は、そのアライにリンクしているヴェルテックのアイテム1つにつき+2[パワー]を得る。

効果（英語原文）

Hindered (This object enters the field rested.)

[REST], Banish Battery Core X: Target ally's next attack against a champion this turn gets +2[POWER] for each VelTech item linked to that ally.

フレーバーテキスト

充電式の携帯型エネルギー貯蔵装置。

このカードの用語

  • 追放（Banish）カードをゲームから取り除く一時的・恒久的な領域。
  • ハインダード（Hindered）このオブジェクトはレスト状態で場に出る。
  • リンク（Link）対象のオブジェクトをリンク先として場に出る能力。リンク先を失うと、このオブジェクトはサクリファイスされる。リンク先の種類に応じて「ユニットリンク」「チャンピオンリンク」「ウェポンリンク」などと表記される。
