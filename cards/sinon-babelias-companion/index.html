効果（英語原文）

[REST], Sacrifice a Powercell: Cascade—
• 1— Draw a card.
• 2— Put a buff counter on each Automaton ally you control.
• 3— Wake up Sinon, Babelia's Companion. Their base power becomes 4.
(This ability changes each cascade.)
