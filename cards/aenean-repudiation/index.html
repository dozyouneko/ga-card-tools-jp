効果（日本語）

アエネアン・プログレッション （このカードは、このゲーム中にアエネアン・プログレッションを持つカードを解決した回数1回につき、起動コストが(2)多くなる。）

各プレイヤーは、自分の手札とメモリーを合わせて7枚になるまでカードを捨てる。あなたがエリュシオンのオブジェクトをコントロールしているなら、各対戦相手はさらにカードを1枚多く捨てる。

効果（英語原文）

Aenean Progression (This card costs (2) more to activate for each time you've resolved a card with Aenean progression this game.)

Each player discards all but seven cards from their hand and/or memory. If you control an Elysian object, each opponent discards an additional card.
