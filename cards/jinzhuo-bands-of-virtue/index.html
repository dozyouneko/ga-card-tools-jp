効果（英語原文）

[Guo Jia Bonus] [REST], Banish Jinzhuo, Bands of Virtue: Scavenge 6 for a Beast ally card. If a card was scavenged this way, put X quest counters on your champion, where X is that card's power stat. X is capped at 4. Otherwise, return Jinzhuo, Bands of Virtue to the field rested. Activate this ability only if you control an object named Fabled Emerald Fatestone.

このカードの用語

  • 追放（Banish）カードをゲームから取り除く一時的・恒久的な領域。
  • スカベンジ（Scavenge N）指定カードを引くかN枚公開するまでデッキ上から公開し、指定カードを手札に、残りをデッキの下へ。
  • クエストカウンター（quest counter）主にチャンピオンに蓄積するカウンター。運命石のトランスフォームやコスト支払いなど、グオ・ジア系のギミックに使う。
